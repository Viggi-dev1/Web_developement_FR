# QR CODE Generator
First steps to setup react app
1. npm create vite@latest
2. name the project
3. chose the language javascript and also chose react
4. cd to the created folder
5. npm install
6. Installed the npm package react-qr-code


The WEB Application contains a input box and the QR code will be dynamically changed, upon addition of input.
